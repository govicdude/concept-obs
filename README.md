## Le concept et l'audience

- Une phrase (logline) : ... le Directeur Gakuganji aspire d'être le meilleur rockstar du monde
- Le public cible : ... Le groupe de domaine des multimédias PM
- La franchise d'origine : ... Jujutsu Kaizen

## L'intrigue

- Le début : ... Gakuganji est un jeune jouer de guitare dans sa bande Les Tufflings
- Le milieu : ... Il font un band battle the beatles
- Le revirement (plot twist) : ... Le bassiste de son band les trahis, parce qu'il n'a pas été remboursé ces 5$
- La fin : ... Gakuganji décide de jouer la basse et la guitare en même temps et bat les beatles 

## Le personnage principal

- Description (physique et psychologique) : ... Calvitie, passionné pas la musique
- Son désir (ce qu'il veut) : ... devenir le meilleur rockstar du monde
- Son besoin (ce qu'il lui faut) : ... Être le champion de la bataille de bandes
- Son évolution : ... Il est très arrogant et croit qu'il n'a pas besoin de pratiquer la guitare.
